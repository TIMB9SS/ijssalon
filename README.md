# BOLLE. — Website van het ijssalon

Deze repository bevat de promotiewebsite voor ons fictieve ijssalon BOLLE., gemaakt voor de opdracht 6BCW.

## Website openen
Open [index.html](index.html) in je browser. De website bevat het concept, onze smaken, prijzen en een mobielvriendelijke navigatie. De pagina werkt zonder backend.

## GitHub Pages instellen
1. Open **Settings → Pages** van deze repository.
2. Kies **Build and deployment → Deploy from a branch**.
3. Selecteer **main** en **/(root)** en bewaar.
4. Controleer de gepubliceerde site op https://timb9ss.github.io/ijssalon/ nadat Pages is geactiveerd.

## Schoolopdracht
De **receptencalculator** bevindt zich in een aparte **private** repository. De PowerPoint voor de pitch en het Business Model Canvas zijn afzonderlijke onderdelen en zijn niet vereist in de publiek toegankelijke website.

Dit is een fictief ijssalon: de getoonde informatie is voor een schoolproject. Afbeeldingen en grafische elementen worden met lokale HTML/CSS/SVG opgebouwd; controleer eventuele latere toegevoegde afbeeldingen op gebruiksrechten.
